# Diagram assets

- `system-architecture-v4.0.0.svg` is generated by
  `scripts/generate_architecture_diagram.py`. It is the canonical architecture
  diagram referenced by `docs/system_architecture.md` and the README.
- `system-architecture-v4.0.0.png` is a 2x raster export of the SVG.

Regenerate both after changing package modules or layer boundaries:

```bash
python scripts/generate_architecture_diagram.py
uv run --no-project --with cairosvg cairosvg assets/system-architecture-v4.0.0.svg \
  -o assets/system-architecture-v4.0.0.png -s 2
```

CairoSVG is used for the PNG because it renders gradients, markers, and dashed
borders. Quick Look on macOS renders tall SVGs into a square thumbnail and crops
the lower layers; ImageMagick's internal MSVG renderer drops gradients and
arrowheads.

Historical diagrams (`system-architecture-v3.1.0.png`,
`system-architecture-v3.2.0.svg`, and `legacy-system-diagram-v3.0.0.*`) are
retained for comparison and are not regenerated.
