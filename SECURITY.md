# Security Policy

## Supported Versions

Use the latest version to ensure you have the most up-to-date security patches.

| Version | Supported          |
| ------- | ------------------ |
| 3.1.x   | :white_check_mark: |
| 3.0.x   | :white_check_mark: |
| 2.0.x   | :x:                |
| 1.x     | :x:                |

## Reporting a Vulnerability

We take security vulnerabilities seriously. If you discover a security issue, please do **NOT** open a public issue.

Instead, please send an email to **muditbhargava666@gmail.com**.

### What to Include
*   Description of the vulnerability.
*   Steps to reproduce the issue.
*   Potential impact.

We will acknowledge your report within 48 hours and provide a timeline for the fix.
